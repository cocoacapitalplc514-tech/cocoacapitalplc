# Cocoa Capital PLC

Official corporate website for Cocoa Capital PLC — a Ghanaian investment and structured finance company focused on financing the cocoa value chain.

## Stack

- Next.js 15 (App Router)
- React 19
- TypeScript
- Tailwind CSS v4
- GSAP + ScrollTrigger
- Framer Motion–compatible patterns
- Lucide React
- React Hook Form + Zod

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — development server (Turbopack)
- `npm run build` — production build
- `npm run start` — start production server
- `npm run lint` — ESLint

## Project Structure

```
src/
  app/                 # App Router pages & layout
  components/
    layout/            # Navbar, Footer
    sections/          # Homepage sections
    ui/                # Shared UI primitives
    seo/               # Schema.org JSON-LD
  lib/                 # Constants & utilities
```
